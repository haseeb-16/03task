About the Course

This course introduces HTML, the language used to structure web pages.

The course starts on November 2, 2026.

Learning HTML is the first step toward understanding how web pages are structured.

As the course introduction explains, practice makes progress.

Reference: HTML Living Standard.

Course Lessons

Lesson 1: HTML Structure

Learn about headings, paragraphs, links, lists, and the basic structure of an HTML document.

Lesson 2: Forms and Tables

Practice creating registration forms, input fields, dropdowns, and tables.

Lesson 3: Semantic HTML and Media

Learn to organize content using semantic tags and add audio, video, images, and embedded pages.

Frequently Asked Questions

What is HTML?

HTML stands for HyperText Markup Language. It structures content on web pages.

Do I need programming experience?

No. This course begins with basic HTML tags and gradually introduces more concepts.

Can I learn HTML without CSS or JavaScript?

Yes. You can learn document structure, links, forms, tables, semantic elements, and media using HTML alone.
